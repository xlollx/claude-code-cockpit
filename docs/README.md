# Documentation

The [README](../README.md) describes every feature of the panel and the chat. This folder holds what sits next to it.

## Guides

Things you install or configure next to cockpit. All of them are optional.

| Guide | What for |
|---|---|
| [OpenCode](guides/opencode.md) | Install, free models (OpenCode, NVIDIA, OpenRouter), handover and delegation |
| [Antigravity CLI](guides/antigravity.md) | Install, sign-in, models, handover and delegation |
| [Delegation](guides/delegation.md) | Let Claude hand read-only work, or write work in a worktree, to OpenCode or Antigravity |
| [Reminders](guides/reminders.md) | The reminders file, the panel, an optional hook for overdue reminders at session start |
| [Skills](guides/skills.md) | Suggested skills, how to add them, Active modes and `other…` |
| [Windows Terminal](guides/windows-terminal.md) | The recommended look, light terminals, updating from PowerShell |
